## 介绍
这是一个用于C#或WPF开发的扩展方法库，其中包含用于Number、Byte、String、Collection等多种类型400多个扩展方法


## 基本使用

* C#通用扩展方法库使用以下命令添加引用，支持.NET Standard 2.0框架
  ``` shell
  dotnet add package IceSky.Extensions
  ```

  
* WPF扩展方法库使用以下命令添加引用，支持.NET 6.0以上框架，其中引用了上面的扩展库
  ``` shell
  dotnet add package IceSky.WpfExtensions
  ```
